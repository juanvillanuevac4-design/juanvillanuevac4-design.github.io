# Portafolio · Juan Villanueva Canouet

PWA instalable que reúne mis aplicativos de operaciones de transporte.

- Vista **Portafolio** (reclutadores): `/#portafolio`
- Vista **Acceso rápido** (colaboradores): `/#colaboradores`

Para agregar o editar un aplicativo, modifica el arreglo `APPS` en `index.html` y sube `C` en `sw.js` (p. ej. `jv-v2`) para refrescar la caché.
